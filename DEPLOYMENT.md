# Deployment Guide

This guide covers deploying the AI Financial Advisor Agent to production.

## Option 1: Deploy to Render (Recommended)

Render provides easy deployment with automatic PostgreSQL and Redis setup.

### Prerequisites

- GitHub account with your code pushed
- Render account (free tier available)
- API credentials (OpenAI, Google, Hubspot)

### Steps

1. **Push Code to GitHub**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```

2. **Connect to Render**
   - Go to [Render Dashboard](https://dashboard.render.com/)
   - Click "New +" → "Blueprint"
   - Connect your GitHub repository
   - Select the repository

3. **Configure Environment Variables**
   
   Render will detect `render.yaml` and prompt for environment variables:

   **Backend Service:**
   - `OPENAI_API_KEY`: Your OpenAI API key
   - `GOOGLE_CLIENT_ID`: From Google Cloud Console
   - `GOOGLE_CLIENT_SECRET`: From Google Cloud Console
   - `GOOGLE_REDIRECT_URI`: `https://your-backend-url.onrender.com/auth/google/callback`
   - `HUBSPOT_CLIENT_ID`: From Hubspot Developer Portal
   - `HUBSPOT_CLIENT_SECRET`: From Hubspot Developer Portal
   - `HUBSPOT_REDIRECT_URI`: `https://your-backend-url.onrender.com/auth/hubspot/callback`
   - `FRONTEND_URL`: `https://your-frontend-url.onrender.com`
   - `DATABASE_URL`: Auto-populated by Render
   - `REDIS_URL`: Auto-populated by Render
   - `SECRET_KEY`: Auto-generated by Render

   **Frontend Service:**
   - `VITE_API_URL`: `https://your-backend-url.onrender.com`

4. **Update OAuth Redirect URIs**
   
   Update redirect URIs in:
   - Google Cloud Console
   - Hubspot App Settings
   
   Use your Render backend URL.

5. **Enable pgvector Extension**
   
   After database is created:
   - Go to your PostgreSQL service in Render
   - Click "Shell"
   - Run: `CREATE EXTENSION IF NOT EXISTS vector;`

6. **Deploy**
   
   Click "Apply" and Render will:
   - Create PostgreSQL database
   - Create Redis instance
   - Deploy backend API
   - Build and deploy frontend

7. **Verify Deployment**
   
   - Visit your frontend URL
   - Test Google login
   - Connect Hubspot
   - Start chatting!

### Render Blueprint Structure

The `render.yaml` file defines:
- Backend web service (FastAPI)
- Frontend static site (React)
- PostgreSQL database with pgvector
- Redis instance

## Option 2: Deploy to Fly.io

Fly.io provides global edge deployment with PostgreSQL.

### Prerequisites

- Fly.io account
- Fly CLI installed

### Steps

1. **Install Fly CLI**
   ```bash
   curl -L https://fly.io/install.sh | sh
   ```

2. **Login to Fly**
   ```bash
   fly auth login
   ```

3. **Create Fly Apps**
   ```bash
   # Backend
   cd backend
   fly launch --name ai-advisor-backend
   
   # Frontend
   cd ../frontend
   fly launch --name ai-advisor-frontend
   ```

4. **Create PostgreSQL**
   ```bash
   fly postgres create --name ai-advisor-db
   fly postgres attach ai-advisor-db -a ai-advisor-backend
   ```

5. **Enable pgvector**
   ```bash
   fly postgres connect -a ai-advisor-db
   CREATE EXTENSION vector;
   \q
   ```

6. **Set Secrets (Backend)**
   ```bash
   fly secrets set \
     OPENAI_API_KEY=xxx \
     GOOGLE_CLIENT_ID=xxx \
     GOOGLE_CLIENT_SECRET=xxx \
     GOOGLE_REDIRECT_URI=https://ai-advisor-backend.fly.dev/auth/google/callback \
     HUBSPOT_CLIENT_ID=xxx \
     HUBSPOT_CLIENT_SECRET=xxx \
     HUBSPOT_REDIRECT_URI=https://ai-advisor-backend.fly.dev/auth/hubspot/callback \
     SECRET_KEY=xxx \
     FRONTEND_URL=https://ai-advisor-frontend.fly.dev \
     -a ai-advisor-backend
   ```

7. **Deploy**
   ```bash
   # Backend
   cd backend
   fly deploy
   
   # Frontend
   cd ../frontend
   fly deploy
   ```

## Option 3: Deploy with Docker

Use Docker Compose for self-hosting on any cloud provider.

### Prerequisites

- Docker and Docker Compose installed
- Cloud VM (AWS EC2, DigitalOcean, etc.)

### Steps

1. **Copy Files to Server**
   ```bash
   scp -r . user@your-server:/app
   ```

2. **SSH into Server**
   ```bash
   ssh user@your-server
   cd /app
   ```

3. **Create .env File**
   ```bash
   # Create .env with all credentials
   nano .env
   ```

4. **Start Services**
   ```bash
   docker-compose up -d
   ```

5. **Check Logs**
   ```bash
   docker-compose logs -f
   ```

6. **Setup Reverse Proxy (Nginx)**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           proxy_pass http://localhost:3000;
       }
       
       location /api {
           proxy_pass http://localhost:8000;
       }
   }
   ```

## Troubleshooting

### Database Connection Errors

```bash
# Check DATABASE_URL format
postgresql+asyncpg://user:pass@host:port/database

# Enable pgvector
psql $DATABASE_URL -c "CREATE EXTENSION IF NOT EXISTS vector;"
```

### OAuth Redirect Issues

- Ensure redirect URIs match exactly (including http/https)
- Check that test users are added to OAuth app
- Verify client IDs and secrets are correct

### Frontend Can't Connect to Backend

- Check CORS settings in backend
- Verify FRONTEND_URL and VITE_API_URL
- Ensure backend is accessible from frontend

### RAG Search Not Working

- Verify pgvector extension is enabled
- Check that embeddings are being created
- Ensure OPENAI_API_KEY is valid

## Scaling Considerations

For production use:

1. **Database**: Upgrade PostgreSQL plan for more connections
2. **Redis**: Add Redis for better caching
3. **Background Jobs**: Use Celery for async tasks
4. **CDN**: Use CloudFlare or similar for static assets
5. **Monitoring**: Add Sentry for error tracking
6. **Rate Limiting**: Add rate limits to API endpoints
7. **Backups**: Set up automated database backups
